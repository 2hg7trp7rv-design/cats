# Cat's tower

ぬいぐるみのような猫たちが古い雑居ビルで暮らし、店舗を経営し、普段の商品を使って侵入ロボからタワーを守る、スマートフォン縦画面専用のWebゲームです。

## 開発対象

- スマートフォンのブラウザのみ
- 縦画面・タッチ操作のみ
- iPhone Safariを最優先
- Android Chromeにも対応
- PC版・横画面版・キーボード操作は対象外
- 課金・広告はV0.1では未実装

## V0.1で遊べる内容

- タワーの上下スワイプ
- ロビー、住居、4業種の店舗
- 4匹のぬいぐるみ風猫
- 猫ごとの職業適性、性格、ごきげん
- 猫の配属・解除
- 商品の発注、時間経過、納品、自動販売、売上回収
- 最大6階までの増築
- 招きベルによる猫の入居
- オフライン進行
- ローカル自動保存
- 夜間防衛
- 2種類の通常敵と1体のボス
- 商品在庫を使う店舗自動攻撃
- 4種類の防衛道具
- 勝利報酬と店舗強化
- ホーム画面追加用のWeb App Manifest
- オフライン再訪用のService Worker

## 起動方法

ビルド工程や依存パッケージはありません。静的ホスティングへそのまま配置します。

ローカル確認では、このディレクトリをHTTPサーバーで配信して`index.html`を開きます。`file://`直開きではService Workerは動きません。

## 保存データ

ブラウザの`localStorage`へ保存します。ブラウザのサイトデータを削除すると進行も削除されます。V0.1ではクラウドセーブはありません。

## 手動確認項目

1. 縦画面でタイトルから開始できる
2. タワーだけが上下に動き、ブラウザ画面が誤スクロールしない
3. 売上を回収できる
4. 新しい階を増築できる
5. 猫を迎え、店舗へ配属できる
6. 発注完了後に納品できる
7. 在庫が自動販売される
8. リロード後に進行が戻る
9. 防衛戦を開始し、4道具を使える
10. 敵撃破後の報酬が経営へ反映される
11. 横向き時に縦向き案内が表示される
12. Dynamic Island・ノッチ・ホームインジケータと主要UIが重ならない

## リポジトリ運用
