# Cat's tower

ぬいぐるみのような猫たちが古い雑居ビルで暮らし、店舗を経営し、普段の商品を使って侵入ロボからタワーを守る、スマートフォン縦画面専用のWebゲームです。

## 現在のバージョン

V0.2。V0.1の基本ループに対して、進行不能対策、初回防衛の導線、敵の視認性、スマートフォンUIの情報階層を改修しています。

## 開発対象

- スマートフォンのブラウザのみ
- 縦画面・タッチ操作のみ
- iPhone Safariを最優先
- Android Chromeにも対応
- PC版・横画面版・キーボード操作は対象外
- 課金・広告は未実装

## V0.2で遊べる内容

- タワーの上下スワイプ
- ロビー、住居、4業種の店舗
- 4匹の猫と職業適性、性格、ごきげん
- 猫の配属・解除
- 商品の発注、時間経過、納品、自動販売、売上回収
- 最大6階までの増築
- 招きベルによる猫の入居
- ローカル自動保存
- オフライン進行
- 所持コイン120未満の間、管理人支援として毎秒1コイン
- 留守中も所持コインが120に届くまで管理人支援を反映
- 初回は稼働店舗1つから開始できる夜間防衛
- 2種類の通常敵と1体のボス
- 商品在庫を使う店舗自動攻撃
- 4種類の防衛道具
- 勝利報酬と店舗強化
- Web App ManifestとService Worker

## 進行不能対策

コインと在庫が同時に0になっても、ゲーム起動中は所持コインが120未満の間、管理人支援として1秒につき1コイン増えます。再訪時も、留守時間に応じて所持コインが120に届くまで補填されます。これにより発注資金を失って完全に進行不能になる状態を防ぎます。

## 起動方法

ビルド工程や依存パッケージはありません。静的ホスティングへそのまま配置します。

ローカル確認では、このディレクトリをHTTPサーバーで配信して`index.html`を開きます。`file://`直開きではService Workerは動きません。

## 保存データ

ブラウザの`localStorage`へ保存します。V0.1の保存キーを維持しているため既存進行は引き継がれます。ブラウザのサイトデータを削除すると進行も削除されます。クラウドセーブは未実装です。

## 自動確認

GitHub ActionsではChromiumとWebKitを用いて、390×844のスマートフォン条件で次を確認します。

1. タイトルから開始できる
2. 増築・保存・再読込が成立する
3. コイン0・在庫0から毎秒収入で復帰できる
4. 初回防衛を稼働店舗1つで開始できる
5. 敵が1階へ即時表示される
6. 道具でエネルギーと敵HPが減る
7. 一時停止・再開・撤退が成立する
8. JavaScriptエラーが発生しない
